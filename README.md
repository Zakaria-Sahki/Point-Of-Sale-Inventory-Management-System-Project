# Point of Sale & Inventory Management System

## 📌 Overview

The **Point of Sale (POS) and Inventory Management System** is a desktop application developed using C# and .NET Windows Forms.

The system is designed to simplify sales operations and inventory management by providing an easy-to-use interface for managing products, tracking stock levels, processing sales, and monitoring business activities.

## ✨ Features

- **Inventory & Product Management:** Add, update, delete, and view products, track stock quantities and monitor inventory levels.
- **Category Management:** Organize products into different categories.
- **Brand Management** Organize products into different Brands.
- **Sales Management:** Process customer purchases and generate sales transactions.
- **Customer Management:** Manage customer information.
- **Supplier Management:** Store and manage supplier information.
- **Reports:** Right now, I am working on Screen of View sales and inventory reports.
- **User Management:** Manage application users and access permissions.

## 🛠️ Technologies Used

- **Programming Language:** C#
- **Framework:** .NET Framework, ADO.NET
- **Desktop Application:** Windows Forms (WinForms)
- **Database:** Microsoft SQL Server.
- **IDE:** Visual Studio
